# Lamban Pesagi — Digital Cultural Heritage & Architectural Museum

Platform dokumentasi dan promosi budaya interaktif untuk **Lamban Pesagi**, rumah panggung tradisional tahan gempa masyarakat adat **Sai Batin** di Pekon Kenali, Kecamatan Belalau, Kabupaten Lampung Barat.

## 🏛️ Identitas & Legalitas Cagar Budaya
- **Situs Cagar Budaya:** Dilindungi UU RI No. 5 Tahun 1992 (No. Registrasi: 397.04.06.05)
- **Warisan Budaya Takbenda (WBTb):** Ditetapkan melalui SK Kemendikbud No. 270/P/2014
- **Lokasi Geografis:** 5°04'05"S 104°08'53"E, Lereng Dataran Tinggi Gunung Pesagi (2.262 mdpl), Pekon Kenali, Belalau, Lampung Barat

## ✨ Fitur Interaktif
1. **Anatomi Tiga Lapisan Arsitektur:**
   - Visualisasi interaktif struktur *Atap & Panggakh*, *Dinding & Ruang (Sesai)*, dan *Pondasi Panggung*.
2. **Eksplorasi Sambungan Kayu Tanpa Paku (Zero-Nail Joinery):**
   - Simulasi *pull-apart / exploded view* untuk 5 teknik sambungan: Tanggam-Purus (Mortise & Tenon), Pasak Kayu, Sambungan Jepit, Sambungan Miring (Scarf Joint), dan Ikatan Ijuk fleksibel peredam seismik.
3. **Denah & Stratifikasi Ruang Adat:**
   - Peta denah 6 zona privasi dan hierarki fungsi sosial masyarakat Sai Batin dengan *room selector pills* dan hotspot interaktif.
4. **Tata Krama Bertamu & Panduan Kunjungan Lapangan:**
   - 4 Protokol etika bertamu ke rumah cagar budaya berpenghuni, panduan musim panen kopi robusta, kabut pagi, serta direktori kontak langsung Pokdarwis Pekon Kenali via WhatsApp dan Google Maps.

## 🎨 Desain & Teknologi
- **Tema Visual:** *Highland Basalt & Robusta Timber* (`#F5F6F5`, `#141716`, `#8E4A23`, `#2C4636`, `#D6973D`)
- **Tipografi:** Google Fonts *Syne* (Display), *DM Sans* (Body), dan *IBM Plex Mono* (Teknis/Data)
- **Arsitektur Kode:** Vanilla HTML5, Modular Vanilla CSS, dan Vanilla ES Modules JavaScript (Zero framework overhead, ultra-fast load time)
- **Responsivitas:** 100% Mobile & Touch-Optimized (Smooth horizontal pills, animated drawer, scroll-lock, 44x44px touch targets)

## 🚀 Menjalankan Secara Lokal
```bash
# Clone repositori
git clone https://github.com/<username>/lamban-pesagi.git

# Jalankan lokal server sederhana (misal menggunakan Python)
python -m http.server 8080
```
Buka peramban pada `http://localhost:8080`.
